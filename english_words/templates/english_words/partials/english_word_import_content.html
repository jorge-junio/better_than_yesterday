Como preparar o arquivo

CSV em UTF-8, separado por vírgulas, com uma linha por significado. A coluna Observação é opcional. Use um significado vazio para uma palavra sem significados.

Palavra,Significado,Observação
APPLE,MAÇÃ,FRUTA
APPLE,MACIEIRA,FRUTA

JSON com uma lista de palavras, cada uma contendo word, note (opcional) e meanings:

[
  {"word": "APPLE", "note": "FRUTA", "meanings": ["MAÇÃ", "MACIEIRA"]}
]
